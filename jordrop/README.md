# JORDROP Esports

JORDROP Esports is a Django web application for esports information. It includes pages for games, teams, players, tournaments, and a wiki system where users can submit edits.

The goal of the project is to create a central place for esports content, similar to a small wiki, with different user roles and moderation.

## Features

- View games, teams, players, and tournaments
- Search across wiki pages, teams, and players
- Create and edit wiki pages
- Submit edits for moderator approval
- View wiki revision history
- Restore previous wiki revisions
- User roles: visitor, contributor, moderator, and admin
- REST API using Django REST Framework
- AI chat assistant using Groq and llama-3.1-8b-instant

## Tech Used

- Python
- Django
- Django REST Framework
- SQLite
- HTML, CSS, and JavaScript
- Groq API
